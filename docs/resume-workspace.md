# فضای مدیریت رزومه‌ها

فرانت با React و Material UI ساخته شده و مسیرهای زیر را دارد:

- `/resumes`: فهرست فایل‌ها، جست‌وجوی نام/فایل/ایمیل، نمایش جزئیات و پیش‌نمایش، اصلاح اطلاعات اصلی و حذف با تأیید.
- `/upload`: انتخاب یا کشیدن چند فایل و بارگذاری و تحلیل ترتیبی آن‌ها. ورود به این صفحه از دکمهٔ داخل فهرست است.
- `/candidates` و `/candidates/:id`: بانک افراد و پروفایل کامل، اختلاف‌ها، ادغام، خلاصهٔ ذخیره‌شده و تاریخچه. [جزئیات](profiles-and-summaries.md)

ورود و ثبت‌نام در `/login` و `/signup` در دسترس‌اند. مسیرهای قدیمی فرانت به فهرست رزومه‌ها هدایت می‌شوند.

## API و داده

`GET /api/resumes` برای هر فایل فقط یک ردیف با آخرین وضعیت تحلیل برمی‌گرداند. صفحه‌بندی با `before` و `limit` انجام می‌شود. فهرست محتوای باینری فایل‌ها را بارگذاری نمی‌کند.

`GET /api/resumes/{id}` جزئیات را می‌خواند و `PATCH` اطلاعات اصلی کاندیدا و مهارت‌ها را اصلاح می‌کند. سوابق کاری و تحصیلات موجود حفظ می‌شوند. ذخیرهٔ فرم، تحلیل نیازمند بررسی را به‌عنوان تأیید انسانی ثبت می‌کند.

`DELETE /api/resumes/{id}` فایل، تلاش‌های تحلیل و خروجی‌های مربوط را حذف می‌کند. اگر کاندیدا فایل دیگری نداشته باشد، پروفایل آن نیز حذف می‌شود. آرشیو مستقل ایمیل خام در این عملیات حذف نمی‌شود. همهٔ درخواست‌ها به سازمان کاربر و RLS محدودند.

پیش از اجرای نسخهٔ جدید، از پوشهٔ `backend` دستور `uv run alembic upgrade head` را اجرا کنید؛ مهاجرت `0005` مجوز محدود حذف را به نقش برنامه می‌دهد.

## اعتبارسنجی

تست‌های `backend/tests/test_resume_workspace.py` ویرایش با حفظ سوابق، حذف واقعی، جداسازی سازمانی، جست‌وجو و صفحه‌بندی را روی دیتابیس آزمایشی بررسی می‌کنند. بررسی مرورگری، جدول، مشاهده، ویرایش، حذف، آپلود، منوی موبایل و ورود را با دادهٔ ساختگی آزمایش می‌کند.
