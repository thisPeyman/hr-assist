# اجرای محلی HR Assist در ویندوز

برای اجرای روزمره پروژه، روی فایل `start.bat` در ریشه پروژه دوبار کلیک کنید. این فایل:

1. وجود وابستگی‌های بک‌اند و فرانت‌اند را بررسی می‌کند.
2. در دسترس بودن PostgreSQL روی پورت `5432` را بررسی می‌کند.
3. بک‌اند را روی `http://127.0.0.1:8000` اجرا می‌کند.
4. فرانت‌اند را روی `http://127.0.0.1:5173` اجرا می‌کند.
5. پس از آماده شدن برنامه، آن را در مرورگر باز می‌کند.

دو پنجره ترمینال برای لاگ‌های Backend و Frontend باز می‌مانند. برای متوقف کردن پروژه، در هر دو پنجره `Ctrl+C` بزنید و سپس پنجره‌ها را ببندید.

بک‌اند با Uvicorn و بدون پردازش reload جداگانه اجرا می‌شود تا اتصال سرویس‌های خارجی مانند Groq در همان پردازش اصلی برقرار بماند. پس از تغییر کد بک‌اند یا فایل `.env`، پنجره Backend را ببندید و `start.bat` را دوباره اجرا کنید.

## آدرس‌ها

- برنامه: <http://127.0.0.1:5173>
- API: <http://127.0.0.1:8000>
- مستندات API: <http://127.0.0.1:8000/docs>
- بررسی سلامت بک‌اند: <http://127.0.0.1:8000/healthz>

## راه‌اندازی اولیه روی سیستم جدید

پیش‌نیازها:

- Python 3.14
- Node.js 22
- PostgreSQL 15 یا جدیدتر، همراه افزونه‌های `pgvector` و `pg_trgm`
- ابزار `uv`

در PowerShell، از ریشه پروژه اجرا کنید:

```powershell
cd backend
uv sync
uv run alembic upgrade head

cd ../frontend
npm install
```

تنظیمات اتصال دیتابیس و سایر متغیرهای محلی در `backend/.env` قرار دارند. این فایل حاوی اطلاعات حساس است و نباید commit شود.

پس از راه‌اندازی اولیه، فقط `start.bat` را اجرا کنید.

برای اجرای اسکریپت از ترمینال بدون باز شدن خودکار مرورگر:

```powershell
.\start.bat --no-browser
```

## خطاهای رایج

### PostgreSQL is not listening

سرویس PostgreSQL را اجرا کنید و مطمئن شوید روی `127.0.0.1:5432` در دسترس است. سپس دوباره `start.bat` را اجرا کنید.

### Backend virtual environment was not found

در پوشه `backend` دستور `uv sync` را اجرا کنید.

### Frontend dependencies were not found

در پوشه `frontend` دستور `npm install` را اجرا کنید.

### پورت 8000 یا 5173 از قبل اشغال است

اسکریپت اجرای سرویس مربوط به آن پورت را رد می‌کند. اگر نمونه‌ای از HR Assist از قبل در حال اجرا باشد، این رفتار طبیعی است. در غیر این صورت، برنامه‌ای که پورت را اشغال کرده ببندید و `start.bat` را دوباره اجرا کنید.
